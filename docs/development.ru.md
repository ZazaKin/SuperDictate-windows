# Разработка SuperDictate

[English](development.md) · **Русский**

В этом репозитории оба приложения. У них общий дизайн и одни и те же числа для
капсулы и черновика, но не общий код: приложение для Windows — на .NET 8 и
WPF, для Mac — на Swift и SwiftUI.

Сначала прочитайте [AGENTS.md](../AGENTS.md): там правила, которые соблюдает
каждое изменение (одна установленная копия, окна, которые не забирают фокус,
загрузки только по щелчку, журналы без текста диктовки и другие).

## Устройство репозитория

| Часть | Где |

## Windows

### Как всё устроено

Приложение — один самодостаточный `SuperDictate.exe` (.NET 8). Распознаватель,
списки пакетов, лицензия и уведомления встроены в него. При первом запуске он
ставит собственный Python из NuGet (сверяя SHA-512) и закреплённые пакеты из
PyPI (сверяя SHA-256 каждого файла) в папку `Runtime` внутри папки установки;
затем пользователь скачивает модель с Hugging Face, закреплённую на конкретном
коммите.

Папка установки (записана как `InstallLocation` в списке приложений):

| Элемент | Что внутри |
|---|---|
| `SuperDictate.exe` | программа; обновление заменяет только её |
| `Uninstall SuperDictate` | удаляет программу (то же, что «Удалить» в списке приложений) |
| `Data` | настройки и история |
| `Models` | модели распознавания, всегда здесь |
| `Runtime` | движок распознавания (свой Python с пакетами) |
| `Logs` | журналы, без текста диктовки |
| `Recordings`, `Temp` | временные записи и загрузки |

### Сборка и проверка

Нужен .NET 8 SDK (`build-app.ps1` найдёт его и в `%LOCALAPPDATA%\dotnet-sdk8`).

```powershell
scripts\build-app.ps1 -OutputDir <папка>       # собрать SuperDictate.exe
<папка>\SuperDictate.exe --self-test           # самопроверка; код 0 — всё прошло
<папка>\SuperDictate.exe --snapshot <папка>    # картинки настроек и капсулы
```

Не запускайте собранную копию напрямую: вне папки установки exe открывает
установщик. Для проверки сборки есть `--self-test`. `--snapshot` рисует
страницы настроек, все обложки капсулы и кадры того, как капсула пишет фразу,
в PNG — с настройками по умолчанию, за пределами экрана; картинки Windows в
README — оттуда.

### Установка для разработки

```powershell
scripts\install-local.ps1
```

Собирает рядом с проектом, запускает самопроверку и устанавливает сборку тем
же кодом, что и установщик для пользователей (`SuperDictate.exe --install`):
заменяет `SuperDictate.exe` в папке установки, не трогая данные, и запускает
приложение. При первой установке можно выбрать папку:
`scripts\install-local.ps1 -InstallRoot D:\SuperDictate`.

Если движок распознавания ещё не установлен в папку установки, самопроверка
пропускает его проверку (строка `SKIP`), чтобы установка прошла; скрипт выпуска
такую сборку не примет.

## Mac

Нужен Mac на Apple Silicon с Xcode 26 или новее для капсулы Liquid Glass
(остальное собирается и в Xcode 16). Без Mac просто отправьте ветку на GitHub:
там приложение соберётся и проверится, а приложение и снимки экрана можно
скачать (см. ниже).

```bash
swift test --package-path macos              # тесты основной логики
bash macos/scripts/build-app.sh              # macos/dist/SuperDictate.app и zip
bash macos/scripts/install-local.sh          # собрать и заменить /Applications/SuperDictate.app
python macos/scripts/make-icon.py            # перерисовать значок (нужен Pillow)
```

| Путь | Что это |
|---|---|
| `Sources/SuperDictateCore` | Черновик, распознавание голоса, подпись, положение и обложки капсулы, языки; без фреймворков Mac, полностью покрыто тестами |
| `Sources/SuperDictate/App` | Приложение и `DictationModel`, которая ведёт диктовку от нажатия клавиши до напечатанного текста |
| `Sources/SuperDictate/Audio` | Запись с микрофона, 16 кГц, моно |
| `Sources/SuperDictate/Speech` | Parakeet TDT v3 через FluidAudio, по одному запросу за раз |
| `Sources/SuperDictate/Input` | Горячая клавиша, печать текста, разрешения |
| `Sources/SuperDictate/UI` | Капсула, панель в строке меню, настройки, окно первой настройки |
| `Resources` | `Info.plist`, entitlements, исходник значка |

Основные правила: идентификатор `com.local.superdictate`; единственная копия,
которую запускают, — `/Applications/SuperDictate.app`; ничто не сбрасывает
разрешения автоматически; запрос разрешения показывает либо системный запрос,
либо одну страницу системных настроек, но не то и другое.

### Сборка на GitHub

Каждое изменение в `macos/` запускает `.github/workflows/macos.yml` на macOS 26:
тесты, сборку приложения и `SuperDictate --snapshot <папка>`, который рисует
все экраны, в светлой и тёмной теме, в PNG. Liquid Glass рисует оконный сервер,
поэтому на картинках — нарисованное стекло, как на macOS 14 и 15; настоящее
стекло проверяйте на Mac с macOS 26.

Скачайте **SuperDictate-macOS** (приложение) и **SuperDictate-screenshots** со
страницы запуска или командой `gh run download <запуск> -n SuperDictate-screenshots`.

## Выпуск

Выпуск содержит оба приложения под одним номером версии.

1. Заполните `release-settings.ini`: версию, репозиторий, отпечаток сертификата
   подписи, способы пожертвований (см. [donations-guide.md](donations-guide.md)),
   и напишите `docs/releases/<версия>.md`. Поставьте ту же версию в
   `CFBundleShortVersionString` в `macos/Resources/Info.plist`.
2. Дважды щёлкните `build-release.cmd`. Окно останется открытым и закончится
   либо «Release ready», либо списком того, что исправить.
3. Отправьте изменения, дождитесь успешной сборки для Mac, скачайте zip
   приложения и назовите его `SuperDictate-macOS-<версия>.zip`; добавьте его
   SHA-256 в `dist\SHA256SUMS.txt`.
4. Создайте выпуск на GitHub с обоими файлами и `SHA256SUMS.txt`, затем
   закоммитьте `dist\update.json` в корень репозитория (только после того, как
   выпуск появится, иначе установленные копии предложат несуществующее
   обновление).

Скрипт сначала проверяет ответы, затем подставляет их: версию — в
`SuperDictate.csproj`, адрес репозитория — в документацию, отпечаток — в
`release-signing.sha1`, способы пожертвований — в последний раздел каждого
README и в `.github/FUNDING.yml` (кнопка Sponsor на GitHub). Сам
`release-settings.ini` встраивается в приложение для Windows: ссылки и
пожертвования на странице **Settings › Support** берутся оттуда, пустые строки
не показываются. Полный порядок выпуска — в
[RELEASE_CHECKLIST.md](../RELEASE_CHECKLIST.md).

Подпись: однажды использованный сертификат закрепляется в
`release-signing.sha1`, и скрипт откажется подписывать другим. Не меняйте
сертификат: к нему привязана репутация SmartScreen. Без отпечатка сборка не
подписана, и пользователи увидят предупреждение SmartScreen.

Самопроверка Windows также распознаёт речь установленным движком и моделями,
поэтому выпуски собираются на компьютере, где SuperDictate уже настроен.
