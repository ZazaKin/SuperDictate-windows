# SuperDictate for Windows 1.0.0

The first public release for Windows.

Download: `SuperDictate-Setup-1.0.0.exe` (a single file, about 165 MB). You can
verify it against `SHA256SUMS.txt`.

## What's new

- **One-file installer.** Run the downloaded file and SuperDictate installs for
  your Windows account without administrator rights. It adds a Start menu
  entry, optionally starts when you sign in, and appears in **Settings › Apps**
  for uninstalling.
- **Everything in one folder you choose.** The default is `SuperDictate` on the
  drive with the most free space, not `C:`. It holds the program, engine,
  models, settings and logs, with **Uninstall SuperDictate** next to the
  program.
- **Guided first run.** SuperDictate downloads its own speech engine (about
  100 MB) and the model you pick, with progress and Cancel. Until setup is
  done, dictation stays off, and the hotkey and microphone button open the
  setup page.
- **Model downloads.** Download any of four Whisper models (Large v3 Turbo,
  Small, Base, Tiny), cancel a download, or delete a model.
- **NVIDIA GPU acceleration**, optional (about 1.3 GB).
- **Microphone button.** A floating button starts and finishes dictation with
  one click, for anyone who'd rather not use hotkeys. Drag it anywhere.
- **Capsule at the top of the screen.** Slides down while you dictate, shows
  your voice level and short messages like "Copied last transcript" or "No
  speech detected".
- **AI cleanup with Ollama.** For the Local LLM engine you can see whether the
  model is installed and download it right from the settings.
- **Hotkey recording:** press the combination you want instead of typing key
  names.
- **Dark, Telegram-style interface.** The window resizes and folds its menu
  into a column of icons when narrow. **Save** applies changes and keeps the
  window open.
- **Its own icon** on the file, the taskbar, the tray and the Start menu.
- **Support page:** support the project (Ko-fi, Buy Me a Coffee, crypto), check
  for and install updates (on a click, with checksum verification), report a
  problem, read the license.
- **Verified downloads.** Python, the engine's packages, models and updates are
  checked against pinned checksums and commits.
- **Reliability.** Unexpected errors are logged and the app keeps running.

## Privacy

Audio and transcripts stay on your PC, and logs contain no transcript text. The
internet is used only for downloads you start yourself and for Cloud LLM AI
cleanup if you turn it on. More in the
[user guide](https://github.com/ZazaKin/SuperDictate-windows/blob/main/docs/user-guide.md#privacy).

## Known limitations

- The installer isn't signed with a certificate yet, so Windows SmartScreen asks
  for confirmation: click **More info** › **Run anyway**. You can verify the
  file against `SHA256SUMS.txt`.
- 64-bit Intel and AMD processors only (no ARM64 build yet).
