# SuperDictate для Windows

[English](README.md) · **Русский**

Локальная диктовка для любого приложения Windows: нажмите горячую клавишу или
плавающую кнопку микрофона, говорите — и текст появится там, где стоит курсор.
Распознавание работает на компьютере через faster-whisper, звук никуда не
отправляется.

Это версия для Windows. Версия для Mac на Apple Silicon лежит в папке
[`macos/`](macos/README.md).

## Установить за минуту

**Нужна 64-разрядная Windows 10 (версия 2004 или новее) или Windows 11.**

1. Скачайте `SuperDictate-Setup-<версия>.exe` со страницы
   [последнего выпуска](https://github.com/ZazaKin/SuperDictate-windows/releases/latest).
2. Запустите его. Если появится окно «Система Windows защитила ваш компьютер»,
   нажмите «Подробнее» › «Выполнить в любом случае».
3. Выберите папку и нажмите **Install**. По умолчанию это `SuperDictate` на
   диске, где больше всего места (не на `C:`, если есть другой диск). Всё, что
   нужно программе, — движок, модели, настройки, логи — будет в этой папке.
   Права администратора не нужны.
4. В открывшихся настройках нажмите **Install** в разделе **Speech runtime**,
   затем **Download** напротив модели (рекомендуется Large v3 Turbo).
5. Когда статус станет **Ready**, нажмите **правый Alt** и говорите. Нажмите
   **правый Alt** ещё раз, чтобы вставить текст. Или нажмите на круглую кнопку
   микрофона.

Первая настройка скачивает движок распознавания (около 100 МБ) и модель (от
75 МБ до 1,5 ГБ). После этого интернет для диктовки не нужен.

Подробно об установке, настройках, AI-чистке текста, приватности, удалении и
решении проблем — в [руководстве пользователя](docs/user-guide.ru.md). Что нового —
в [заметках к выпускам](docs/releases/).

## Обновления

Откройте **Settings › Support** и нажмите **Check for updates**. Если вышла
новая версия, **Download and install** скачает её, проверит контрольную сумму и
запустит установщик. Сама программа в интернет не ходит — только по этой кнопке.

## Нашли ошибку?

Опишите её в [GitHub Issues](https://github.com/ZazaKin/SuperDictate-windows/issues/new)
(в приложении: **Settings › Support › Report a problem**). О проблемах
безопасности пишите по [SECURITY.md](SECURITY.md).

## Данные и приватность

- Звук и расшифровки остаются на компьютере; в логах нет текста расшифровок.
- Интернет используется только по кнопкам: загрузка движка, моделей, моделей
  Ollama, проверка обновлений — и для AI-чистки Cloud LLM, если вы её включите.
- Ключ API для AI-чистки хранится в диспетчере учётных данных Windows.
- Всё хранится в одной папке, выбранной при установке: программа, движок,
  модели, настройки, история и логи. Вне её остаются только ярлыки, запись в
  «Приложениях» и ключ API в диспетчере учётных данных.
- Аккаунтов, рекламы, аналитики и телеметрии нет.

Подробнее: [PRIVACY.md](PRIVACY.md).

### Устройство

| Часть | Где |
|---|---|
| Приложение WPF: настройки, трей, капсула, кнопка микрофона, установщик | `src/SuperDictate` |
| Процесс распознавания (Python, faster-whisper), встроен в exe | `src/SuperDictate/worker.py` |
| Закреплённые версии и SHA-256 пакетов движка (CPU и NVIDIA GPU) | `src/SuperDictate/runtime-requirements*.txt` |
| Ответы для выпуска: версия, репозиторий, подпись, пожертвования | `release-settings.ini` |
| Скрипты сборки, установки и выпуска | `scripts/` |
| Готовые файлы выпуска (не хранятся в репозитории) | `dist/` |

Приложение — один самодостаточный `SuperDictate.exe` (.NET 8). Процесс
распознавания, списки пакетов, лицензия и уведомления встроены в него. При
первом запуске он ставит собственный Python из NuGet (с проверкой SHA-512) и
закреплённые пакеты из PyPI (с проверкой SHA-256 каждого файла) в
`Runtime` в папке установки, затем пользователь скачивает модель с Hugging
Face, закреплённую на конкретном коммите.

Папка установки (путь записан как `InstallLocation` в записи «Приложений»):

| Папка | Что в ней |
|---|---|
| `SuperDictate.exe` | сама программа; обновление заменяет только её |
| `Uninstall SuperDictate` | удаляет программу (то же, что «Удалить» в «Приложениях») |
| `Data` | настройки и история |
| `Models` | модели распознавания — всегда здесь |
| `Runtime` | движок распознавания (свой Python с пакетами) |
| `Logs` | логи — без текста расшифровок |
| `Recordings`, `Temp` | временные файлы записи и загрузок |

### Сборка и проверка

Нужен .NET 8 SDK (`build-app.ps1` находит его и в `%LOCALAPPDATA%\dotnet-sdk8`).

```powershell
scripts\build-app.ps1 -OutputDir <папка>   # собрать SuperDictate.exe
<папка>\SuperDictate.exe --self-test       # самопроверка; код выхода 0 — всё прошло
```

Не запускайте собранную копию напрямую: вне папки установки exe открывает свой
установщик. Для проверки используйте `--self-test`.

### Установка для разработки

```powershell
scripts\install-local.ps1
```

Собирает программу рядом с проектом, запускает самопроверку и устанавливает
сборку тем же кодом, что и установщик для пользователей
(`SuperDictate.exe --install`): заменяет `SuperDictate.exe` в папке установки,
не трогая данные, и запускает программу. При первой установке папку можно задать:
`scripts\install-local.ps1 -InstallRoot D:\SuperDictate`.

Если движок распознавания ещё не установлен в папке установки, самопроверка
пропускает его проверку (строка `SKIP`), чтобы установка прошла; скрипт
выпуска такую сборку не примет.

### Выпуск

1. Впишите ответы в `release-settings.ini`: версию, репозиторий, отпечаток
   сертификата подписи (если есть) и способы пожертвований. Как завести
   пожертвования — в [docs/donations-guide.md](docs/donations-guide.md).
2. Дважды щёлкните `build-release.cmd`. Окно не закроется само: в конце будет
   либо «Release ready», либо список того, что исправить.

Скрипт сначала проверяет ответы, затем подставляет их туда, где они нужны:
версию — в `SuperDictate.csproj`, адрес репозитория — в документацию,
отпечаток — в `release-signing.sha1`, способы пожертвований — в последний
раздел этого README и в `.github/FUNDING.yml` (кнопка Sponsor на GitHub). Сам `release-settings.ini` встраивается в
программу: ссылки и пожертвования на странице **Settings › Support** берутся
оттуда, пустые строки не показываются. После успешной самопроверки в `dist\`
появляются установщик `SuperDictate-Setup-<версия>.exe`, `SHA256SUMS.txt` и
`update.json`. Полный порядок выпуска — в
[RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md).

Подпись: однажды использованный сертификат закрепляется в
`release-signing.sha1`, и скрипт откажется подписывать другим. Не меняйте
сертификат: к нему привязана репутация SmartScreen. Без отпечатка сборка не
подписана, и пользователи увидят предупреждение SmartScreen.

Самопроверка также распознаёт речь установленным движком и моделями, поэтому
выпуски собираются на компьютере, где SuperDictate уже настроен.
